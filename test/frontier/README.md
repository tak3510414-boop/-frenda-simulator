## Ver1.01 - バッグ満杯時の足元交換
- 足元アイテムがあり、同種スタックもできずバッグ10枠が満杯の場合、コマンドを「拾う」から「交換」へ自動切替。
- 交換画面でバッグ内の1種類を選ぶと、足元アイテムを取得し、選んだ種類を足元へ置く。交換は1ターン消費。
- バッグは同種を1枠にまとめる現行仕様のため、交換に選んだ種類が複数個なら、その種類のスタック全体を足元へ置く。
- 同じ種類をすでにバッグに持っている場合は、満杯でも従来どおりそのまま拾ってスタック可能。
- 足元にはアイテム画像・名前・個数と「拾える／バッグ満杯：交換」を簡易表示。

## Ver1.00 - バッグ整理・投げる／置く／足元から拾う
- 持ち物の各アイテムをタップすると「使う／投げる／置く」を選べるように変更。素材など使用効果のない物も「投げる／置く」が可能。
- 「置く」は1個を足元へ置き、床アイテムとして残す。足元に別アイテムがある場所、階段、宝箱では置けない。
- バッグ満杯で自動取得できなかった床アイテムは消えずに残り、足元にある間はコマンドの「階段」位置が「拾う」へ切り替わる。
- バッグ整理後、「拾う」で移動せずその場から再取得できる。取得成功時は1ターン消費。
- 一般アイテムも現在向いている方向へ最大6マス投げられる。敵に当たれば3ダメージ、外した場合は着地点へ床アイテムとして残る。
- 投げ石は従来どおり7ダメージで、外した場合は1個消費。火花の杖は従来どおり「使う」で発動。
- 「置く」「投げる」「拾う」は敵ターンを進める通常行動として扱う。

## Ver0.98 - 危険技の予兆・敵情報

- 遠距離・状態異常・高威力の危険技は、使用前に「⚠️ ○○を狙っている！」と1ターン予告します。
- 予告中に射線を切る／間合いを外す／眠らせる／倒すと、その危険技を不発にできます。
- 通常攻撃や危険度の低い技は従来どおり即時行動し、テンポを維持します。
- 敵をタップすると、HP目安・AI傾向・確認できている技・射程・危険度・次の予告技を一時表示します。
- 敵タップによる攻撃操作はVer0.97以前と同じで、情報表示のために追加ターンは消費しません。

## Ver0.97 - 敵ポケモンの技・AI個性化
- 敵の特殊行動をAIタイプだけで決めず、MasterDBの実際の技名と能力傾向から判定。
- 技に応じて、近接強打・遠距離技・状態変化・俊敏技などを使い分ける。
- 遠距離系の実技は浅層3マス、中層4マス、深層5マスを上限として直線射程を持つ。
- 状態異常はVer0.96同様「対応する実技名」のみ。タイプだけでは付与しない。
- 純粋な状態変化技はダメージ0で状態異常を狙い、攻撃技の追加状態異常は低確率に抑える。
- 浅層は特殊技の使用率と再使用間隔を控えめにし、深層ほど徐々に強化。
- 俊敏型・遠距離型は技使用後、一定確率で1マス間合いを取る。
- 待伏型・守備型など従来の追跡個性も維持。

## Ver0.81 - 敵ポケモンの「わざ」／特殊攻撃 第1段階

- 通常攻撃に加え、野生ポケモンがMasterDB由来の**固有のわざ名**を使うようにした。
- 隣接時はAIタイプに応じた確率で特殊攻撃。接近型・待伏型はやや強め、守備型・俊敏型なども時々わざを使う。
- 遠隔型／支援型は、プレーヤーが上下左右・斜めの一直線上にいる場合、**2～4マス**から技を使用できる。壁や別の敵が途中にいる場合は届かない。
- 特殊攻撃には2～3ターン程度の再使用待ちを持たせ、毎ターン連発しない。
- 攻撃時は従来の敵踏み込み・プレーヤー被弾・ダメージ数値に加え、**わざ名を敵の近くへ短く表示**する。遠隔技は専用の発光エフェクト。
- ダメージ計算は既存の装備防御・軽減をそのまま使用。Ver0.81時点では状態異常は未実装。
- Ver0.80の「シングル＝1歩／ダブル＝指定地点まで安全自動移動」、階段到着時の自動選択、30F構成、自動マップ、満腹度、罠などは維持。


## Ver0.80 - シングル1歩／ダブルで目的地まで自動移動
- **1回タップ／1回クリック**：指定方向へ1歩だけ進みます。
- **ダブルタップ／ダブルクリック**：最初に指定した探索済みマスまで、既知の通路を使って自動移動します。
- 自動移動中も1マスごとに通常ターンを消費し、敵も通常どおり行動します。
- 敵を発見した時、攻撃を受けた時、罠が発動した時、進路が塞がれた時はその場で停止します。
- 途中にアイテム・宝箱・階段・発見済み罠がある場合も安全側で停止します（目的地そのものの場合は到着可能）。
- 未探索マスへの自動経路探索はしません。
- iPhone Safariのダブルタップ拡大はダンジョンキャンバス内で抑制します。
- 長押しダッシュ／Shift＋クリックはポインタ操作から廃止しました。PCのShift＋方向キーによる直線ダッシュは補助操作として残しています。
- Ver0.79の階段到着時自動選択、Ver0.77の敵攻撃演出などは維持しています。

## Ver0.78 - 本家風ダッシュ移動
- **通常タップ／クリックは従来どおり1ターン＝1歩**。離れた探索済みマスを指定しても、次の1歩だけ進む。
- iPhone／タッチ操作は、進みたい方向のマップを**約0.36秒長押し**するとダッシュ開始。
- PCは**Shift＋方向キー**または**Shift＋クリック**でダッシュ。マウス長押しにも対応。
- ダッシュ中も1マスごとに通常ターンを消費し、敵も毎ターン行動する。
- 本家の「何かある場所で止まる」考え方に合わせ、**敵・アイテム・宝箱・階段・発見済み罠・通路の分かれ道**で自動停止。
- 未発見の罠は事前には分からないため踏む可能性があり、発動した時点でダッシュ停止。
- 敵から攻撃を受けた場合も即停止。Ver0.77の敵攻撃アニメーションは維持。
- ダッシュは直進のみで、曲がり角や壁では停止する。自動経路探索で勝手に曲がり続ける方式にはしていない。

## Ver0.76 - 本家寄りの満腹度／パン方式

- Ver0.75の罠多めTEST設定、自動マップ、アイテム・宝箱表示などは維持。

## Ver0.74 - 見えない罠／発見後マップ表示

- ダンジョン床に**見えない罠**を配置。未発見の罠は通常画面にも青い自動マップにも表示しない。
- 冒険者が罠を踏むと、その場で**発見＋発動**する。発見後は床上に罠模様を表示し、視界外へ出ても青い自動マップ上にピンク系の小記号として残る。
- 今回の罠は3種類。
  - **トゲの罠**：HPダメージ。
  - **空腹の罠**：食料を減らす。
  - **ワープの罠**：同じ階の別の床へ移動。
- 発見済みの罠は消えず、再び踏むと再発動する。階段・床アイテム・宝箱の自動マップ表示ルールはVer0.73を維持。
- 罠の総数はHUDに出さず、未発見の罠の存在や位置を事前に漏らさない。

## Ver0.73 - 自動マップにアイテム／宝箱を表示

- Ver0.72の青い自動マップを継承。

- 宝箱を**開けると地図記号も消える**。
- 階段は従来どおり、一度発見すると地図に残る。
- 敵は常時地図表示しない。未発見アイテム／宝箱も地図には出さない。

## Ver0.72 - 探索で広がる自動マップ

- 「不思議のダンジョン」系を基準に、**探索済みの部屋・通路が青い半透明マップとして蓄積する自動マップ**を追加。

- 一度見つけた**階段は視界外になっても自動マップに残る**。
- 現在位置は白い小マーカーで表示。
- 宝箱・床アイテム・敵の自動マップ記号は今回は未実装。まず地図本体の見え方を確認する。

- 主人公のタップ移動を経路点間の補間移動に変更し、歩行を滑らかに調整。
- NPCを主人公と同じ道の衝突マスクで制限。柵・芝生・建物の向こうへ抜けない。
- NPC同士の接触を避け、旅人・案内人・市場のお手伝いの名前、役割、複数の会話を追加。
- 主人公と町の人の表示サイズを引き続き同じ基準に統一。
- セーブ形式・既存データは変更なし。

- NPCの道上歩行、表示ピクセル寸法、往復移動、レイヤーON/OFFを確認。

## Ver1.25 — 歩きやすさ・人・町と洞窟の更新

- タップの目的地を道の近くまで許容し、広げた舗装路の範囲へ吸着するようにしました。
- プレーヤーの歩行中にNPCの見た目サイズを基準に距離を取り、通行待ちが長引く場合は止まって再操作を案内します。
- 洞窟ダンジョンに岩肌・鉱脈を感じる石床と壁の色・質感を追加しました。森のダンジョンは従来の苔・土色を維持します。
- 町全体の家屋・施設と、家の中への移動・町への帰還は既存の構築を継承し、町メニューから操作できます。
