# Frenda Frontier Ver0.82 / TEST

## Ver0.82 - 状態異常 第1段階
- 敵の特殊攻撃で「どく／まひ／ねむり／こんらん」が発生する。
- どく：自然回復を止め、4ターンごとにHP-2。
- まひ：行動時に35%で動けず、そのターンを消費。
- ねむり：行動できず、数ターンで自然回復。
- こんらん：移動方向や攻撃方向が乱れる。
- HUDに状態名と残りターンを表示。状態異常になった時は被弾位置にも短い表示を出す。
- ダブルタップ／ダブルクリック自動移動は、行動を乱す状態異常中は開始せず、移動中に発症した場合も即停止。
- 状態異常は階をまたいで継続する。
- 状態回復専用アイテムはまだ未実装（次段階候補）。

## Ver0.81 - 敵ポケモンの「わざ」／特殊攻撃 第1段階

- 通常攻撃に加え、野生ポケモンがMasterDB由来の**固有のわざ名**を使うようにした。
- 隣接時はAIタイプに応じた確率で特殊攻撃。接近型・待伏型はやや強め、守備型・俊敏型なども時々わざを使う。
- 遠隔型／支援型は、プレーヤーが上下左右・斜めの一直線上にいる場合、**2～4マス**から技を使用できる。壁や別の敵が途中にいる場合は届かない。
- 特殊攻撃には2～3ターン程度の再使用待ちを持たせ、毎ターン連発しない。
- 攻撃時は従来の敵踏み込み・プレーヤー被弾・ダメージ数値に加え、**わざ名を敵の近くへ短く表示**する。遠隔技は専用の発光エフェクト。
- ダメージ計算は既存の装備防御・軽減をそのまま使用。Ver0.81時点では状態異常は未実装。
- Ver0.80の「シングル＝1歩／ダブル＝指定地点まで安全自動移動」、階段到着時の自動選択、30F構成、自動マップ、満腹度、罠などは維持。


## Ver0.80 - シングル1歩／ダブルで目的地まで自動移動
- **1回タップ／1回クリック**：指定方向へ1歩だけ進みます。
- **ダブルタップ／ダブルクリック**：最初に指定した探索済みマスまで、既知の通路を使って自動移動します。
- 自動移動中も1マスごとに通常ターンを消費し、敵も通常どおり行動します。
- 敵を発見した時、攻撃を受けた時、罠が発動した時、進路が塞がれた時はその場で停止します。
- 途中にアイテム・宝箱・階段・発見済み罠がある場合も安全側で停止します（目的地そのものの場合は到着可能）。
- 未探索マスへの自動経路探索はしません。
- iPhone Safariのダブルタップ拡大はダンジョンキャンバス内で抑制します。
- 長押しダッシュ／Shift＋クリックはポインタ操作から廃止しました。PCのShift＋方向キーによる直線ダッシュは補助操作として残しています。
- Ver0.79の階段到着時自動選択、Ver0.77の敵攻撃演出などは維持しています。

## Ver0.78 - 本家風ダッシュ移動
- **通常タップ／クリックは従来どおり1ターン＝1歩**。離れた探索済みマスを指定しても、次の1歩だけ進む。
- iPhone／タッチ操作は、進みたい方向のマップを**約0.36秒長押し**するとダッシュ開始。
- PCは**Shift＋方向キー**または**Shift＋クリック**でダッシュ。マウス長押しにも対応。
- ダッシュ中も1マスごとに通常ターンを消費し、敵も毎ターン行動する。
- 本家の「何かある場所で止まる」考え方に合わせ、**敵・アイテム・宝箱・階段・発見済み罠・通路の分かれ道**で自動停止。
- 未発見の罠は事前には分からないため踏む可能性があり、発動した時点でダッシュ停止。
- 敵から攻撃を受けた場合も即停止。Ver0.77の敵攻撃アニメーションは維持。
- ダッシュは直進のみで、曲がり角や壁では停止する。自動経路探索で勝手に曲がり続ける方式にはしていない。

## Ver0.77 - 敵攻撃の視認性改善
- 隣接した敵ポケモンが攻撃すると、プレーヤー方向へ短く踏み込むアニメーションを表示。
- 被弾時、冒険者を短く揺らして明滅させる。
- 被ダメージ値を冒険者の上へフロート表示。
- 遠距離AIの攻撃は通常攻撃と区別したエフェクトで表示。
- 複数の敵が同一ターンに攻撃した場合は、短い間隔をあけて順番に演出する。
- 戦闘計算・ダメージ量・敵AIそのものはVer0.76から変更していない。

## Ver0.76 - 本家寄りの満腹度／パン方式

- ダンジョンの「食料」数値を廃止し、**満腹度 100/100**へ変更。
- 満腹度は通常、**10ターンごとに1減少**する。
- 満腹度が0になると、**毎ターンHPが1減少**する。
- **パン**：満腹度+50。
- **大きなパン**：満腹度+100。
- 薬草は従来のHP14回復に加え、満腹度も+5。
- 階段で次の階へ進んでも、満腹度・HPは自動回復しない。
- 各階にテスト確認用としてパンを最低1個、薬草を最低1個配置。残りの床アイテムからもパン系がランダム出現する。
- 宝箱の「満腹度を直接回復」は廃止し、パン／大きなパンを入手する方式へ変更。
- 空腹の罠は満腹度-10。
- Ver0.75の罠多めTEST設定、自動マップ、アイテム・宝箱表示などは維持。

## Ver0.74 - 見えない罠／発見後マップ表示

- ダンジョン床に**見えない罠**を配置。未発見の罠は通常画面にも青い自動マップにも表示しない。
- 冒険者が罠を踏むと、その場で**発見＋発動**する。発見後は床上に罠模様を表示し、視界外へ出ても青い自動マップ上にピンク系の小記号として残る。
- 今回の罠は3種類。
  - **トゲの罠**：HPダメージ。
  - **空腹の罠**：食料を減らす。
  - **ワープの罠**：同じ階の別の床へ移動。
- 発見済みの罠は消えず、再び踏むと再発動する。階段・床アイテム・宝箱の自動マップ表示ルールはVer0.73を維持。
- 罠の総数はHUDに出さず、未発見の罠の存在や位置を事前に漏らさない。

## Ver0.73 - 自動マップにアイテム／宝箱を表示

- Ver0.72の青い自動マップを継承。
- **一度視界に入った床アイテム**を自動マップ上に明るい小マーカーで表示。視界外へ移動しても、そのアイテムが床に残っている間は地図に残る。
- 床アイテムを**拾うとマーカーも即座に消える**。バッグ満杯などで拾えなかった場合は床に残るため、地図記号も残る。
- **一度発見した未開封宝箱**をオレンジ系の別マーカーで表示。
- 宝箱を**開けると地図記号も消える**。
- 階段は従来どおり、一度発見すると地図に残る。
- 敵は常時地図表示しない。未発見アイテム／宝箱も地図には出さない。

## Ver0.72 - 探索で広がる自動マップ

- 「不思議のダンジョン」系を基準に、**探索済みの部屋・通路が青い半透明マップとして蓄積する自動マップ**を追加。
- 自動マップは追従カメラとは別の**フロア全体縮尺**で重ねて表示するため、歩いた範囲が段々つながって地図になる。
- 部屋へ入った時は現在の視界仕様に従って部屋全体が地図化され、通路は進んだ周辺だけが伸びていく。
- **未探索エリアは地図に出さない**。壁も未探索部分を推測できる形では表示しない。
- 一度見つけた**階段は視界外になっても自動マップに残る**。
- 現在位置は白い小マーカーで表示。
- 宝箱・床アイテム・敵の自動マップ記号は今回は未実装。まず地図本体の見え方を確認する。
- Ver0.71のB1F～B30F構成、Ver0.69の主人公4方向スプライト、Ver0.70の「冒険者Lv」表記を維持。
