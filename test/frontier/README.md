# Frenda Frontier Ver0.39 / TEST

## Ver0.39 - エリア実マップ共通仕様

Ver0.38で「中心開拓地 ↔ 南の街道沿い」の実機往復を確認できたため、北・東・西を個別実装する前に、全エリアへ共通するSceneSpecを実装した版です。

### 今回の主な変更

- 全エリアを `Area SceneSpec v1` で管理
- 1000×1000の論理座標から現在のCanvasへコンパイル
- 共通管理対象
  - 主要通行域
  - 施設配置枠
  - 工事用退避域
  - NPC活動域
  - ランドマーク枠
  - 物流・裏動線
  - エリア入口・出口
  - 将来拡張port
- エリアの性格に応じたテンプレートを用意
  - 中心・広場型
  - 街道・回廊型
  - 森・枝分かれ型
  - 川辺・水路型
  - 高台・段丘型
- `📐 エリア仕様` 画面で各エリアの共通規格を確認可能
- 施設枠数・ランドマーク枠数・接続portなどを自動検証
- 実マップ用navが未作成のエリアでも、SceneSpecから共通navの雛形を生成可能
- 既存の中心開拓地・南の街道の authored nav はそのまま優先し、Ver0.38の往復移動を維持

### 設計上の重要点

Ver0.39では、建物の最終座標や道路形状を固定していません。まず「そのエリアに必要な役割と空間」を確保し、全体マップが固まった後に正式な背景画像・当たり判定・NPC生活ルートへ落とし込みます。

これにより、今後エリアが増えたり全体マップのバランスが変わっても、中心マップを基準に作り直す手戻りを抑えます。

### 配置

今回も画像アセットは変更していません。Ver0.33以降の既存PNGをそのまま使用し、このZIP内の `test/frontier/` の7ファイルを `/test/frontier/` へ上書きしてください。
