# Frenda Frontier Ver0.32 / TEST

Updated: 2026-10-19

## Ver0.32

- 施設の即時完成を廃止し、建設プロジェクト方式へ変更。
- 共通工程：建設予定地 → 資材搬入 → 骨組み工事 → 仕上げ工事 → 完成。
- 工事中の施設は町画面へ建設現場として描画し、工程ごとに資材・杭・骨組み等が増える。
- 工事現場は通行判定にも反映し、工程に応じて立入範囲が変わる。
- 冒険から帰還して日が進むたび、進行中の工事が1段階進む。
- TESTでは「町を発展させる」画面から工事を1段階ずつ進めて確認可能。
- 施設追加を前提に、`CONSTRUCTION_PHASES` / `FACILITY_SITES` / `projects` を共通化。
- 旧Ver0.31以前のセーブは schemaVersion 6 へ自動移行。

## 配置

ZIP内の `test/frontier/` の中身を、そのまま GitHub の `/test/frontier/` へ上書きしてください。
サブフォルダ `assets` は不要です。

## 継続機能

- 町をタップして主人公が移動
- 相棒追従
- 12px単位の通行判定
- 施設・景観レイヤー由来の collision / interaction / area gate
- 移動位置保存
- TEST通行オーバーレイ
- 町域拡張システム
