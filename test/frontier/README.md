# Frenda Frontier Ver0.37 / TEST

Updated: 2026-10-19

## Ver0.37 - 世界構造Ver4 / エリア間移動方式の正式化

町全体の実マップ制作前に、エリア同士を「どう移動するか」をデータ構造として確定しました。

### 正式方針
- 隣接エリア：主人公が実際に道・橋・階段などの境界まで歩き、短い画面切替で隣エリアへ入る「疑似シームレス」
- 遠距離：町が大きくなった後、馬車・船などの移動拠点から目的地を選択する高速移動
- 隣接地区の移動に確認ダイアログは原則出さない
- 実マップ未作成のエリアへは、現段階では論理接続のみ保持する

### 接続データ
`AREA_CONNECTION_DEFS` に `travel.mode / autoTransition / fastTravel` を追加。
`CONNECTION_KIND_DEFS` で森道・街道・橋・階段・馬車・船などの接続種別を定義します。
新しい交通手段を追加しても既存エリア描画ロジックを作り直さない構造です。

### UI
「町域 → 全体マップ」で各接続の、
- 接続地形
- 歩行 / 高速移動
- 境界自動切替の有無
- 開通状態
を確認できます。
「いどう」画面にも現在地から隣接する歩行ルートを表示します。

### 将来の実マップ連携
各エリアの実マップが完成した段階で、現在の接続定義と `nav.exits` を接続します。
境界到達 → 短いトランジション → 次エリア入口へスポーン、までを共通処理に接続できる土台です。

### セーブ
`schemaVersion 9`。将来の高速移動ノード用領域を追加し、旧 Ver0.36 以前のセーブは自動移行します。
