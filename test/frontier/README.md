# Frenda Frontier Ver0.71 / TEST

## Ver0.71 - はじまりの森を30F化

- 「不思議のダンジョン」系の基本構造を基準に、はじまりの森を **B1F～B30F** へ拡張。
- 5階ごとに深度帯を設定。
  - B1～5F：森の入口
  - B6～10F：森の中腹
  - B11～15F：深い森
  - B16～20F：古樹の森
  - B21～25F：森の深奥
  - B26～30F：最深部
- 深くなるほど、出現候補に珍しい／強いポケモンが加わる。
- 装備品の解禁階を30F構成に合わせて分散。
- 30F攻略が成立するよう、敵能力の階層上昇を緩やかに調整。
- 食料は毎ターンではなく **3ターンごとに1消費**。旅のお守りの「6ターンごとに消費を抑える」効果も食料消費タイミングに連動。
- 階段画面に「現在階 / 全30F」と次の階を明示。B30Fの到達点から踏破帰還する。
- Ver0.69で合格した人間主人公4方向スプライト、Ver0.70の「冒険者Lv」表記を維持。

## 継続中のダンジョン基準

- 32×24フロア、部屋＋1マス通路、11×9追従カメラ。
- 部屋／通路で変わる視界、探索済み記憶。
- 8方向移動・斜め攻撃・角抜け禁止。
- 人間主人公1人で探索し、敵は野生ポケモン。
- 武器／防具／お守り、床素材、宝箱、帰還判断。

## Ver0.69 - 人間主人公4方向スプライトの品質統一

- Ver0.66の人間主人公・武器射程・命中・急所・防具・お守り・薬草を継承。
- 攻撃時に装備武器ごとの短いモーションを表示。
  - 剣：斬る
  - 槍：突く
  - 弓：矢を飛ばす
  - ハンマー：振り下ろす
- 床に落ちている素材は生成時点で種類を確定。
- 木材／薬草／鉄のかけら／森の結晶を、拾う前から別の見た目で表示。
- 現在視界内で主人公から2マス以内なら、床アイテム名も表示。
- 宝箱の中身は宝箱としての楽しみを残すため、開けるまでは未判明のまま。
- 32×24フロア、部屋＋通路、11×9追従カメラ、視界制限、探索済み記憶、8方向移動、斜め攻撃、角抜け禁止を維持。


### Ver0.70 追加
- 人間主人公の向きを4方向表示。上=背面、下=正面、左右=横向き。
- 斜め移動・斜め攻撃時も既存playerFacingに従って自然な左右/上下向きへ切替。
- 武器攻撃FXは向き情報と同じ方向を使用。


### Ver0.70 品質統一
- 正面／背面／左／右を同じキャラクターデザイン・頭身・服装・描画密度で統一。
- Ver0.68の簡易正面／横向き素材は使用停止。
- 左右は専用画像を使用し、左右反転による帽子・バッグの不自然さを避ける。
- 町の主人公表示も同じ背面素材へ統一。
