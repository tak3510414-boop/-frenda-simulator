# Frenda Frontier Ver0.36 / TEST

Updated: 2026-10-19

## Ver0.36 - 全体マップ構造 Ver3

Ver0.33までの中心開拓地は「町エンジン検証用の試作マップ」であり、最終マップではありません。
Ver0.34-0.35で接続エリア方式へ移行し、Ver0.36では実マップ制作前に町全体のバランスを決めるためのエリア計画情報を追加しました。

### エリアごとに持つ情報
- `sizeClass` : 小区画 / 標準 / 広域 / 中心区画
- `terrainTags` : 森・川・高台・街道などの地形特性
- `capacity` : 施設・ランドマーク・住民の収容目安
- `travelCost` : エリア間移動の重さ
- `expansionProfiles` : その先へ接続できる将来エリア候補
- 実マップの道路・施設・NPC座標はまだ固定しない

### 将来エリア
`EXPANSION_TEMPLATE_DEFS` を追加。深い森、牧草地、山すそ、採石場候補地、川向こう、湿地、交易路、平原、高原などをテンプレートとして持ちます。
既存エリアからの将来接続候補はテンプレートを参照して自動生成するため、リリース後に新しい地区が増えても全体マップ本体のロジックを書き換える必要はありません。

### 全体マップ UI
「町域」→「全体マップ」で Ver3 を確認できます。
現在の5エリアだけでなく、その外側へ伸びる候補エリア、地形、規模、収容量、移動コストを表示します。

### セーブ
`schemaVersion 8`。`townWorld.structureVersion` を追加。旧 Ver0.35 以前のセーブは自動移行します。

## 配置
`/test/frontier/` 直下へこのZIP内のファイルを上書きしてください。画像アセットはVer0.33から変更していないため、このZIPには重複収録していません。
