# Frenda Frontier Ver0.04（TEST）

配置先: `/test/frontier/`

## この版で遊べる範囲
- 既存の所持ピックを読み込み、★3以下から相棒を選択
- 「はじまりの森」全3階のターン制探索
- プレイヤー移動／相棒の自動戦闘／敵行動
- 採取、10種類枠バッグ、食料、脱出ロープ、敗北時の一部ロスト
- 階段ごとの帰還／続行
- 帰還品をFrontier専用倉庫へ保存
- 商品棚3枠、価格設定、お客さんの来店・購入
- 売上・町発展・簡易ストーリー進行
- 「幻の大秘宝」導入と最初の噂まで

## 既存アプリへの影響
既存ファイルは変更しません。Frontierは新規キー `frenda:frontier:v1` のみ使用します。
所持ピックは既存 `frenda:owned:v1` を読み取り専用で参照します。

## Ver0.04 changes
- 町・店・自宅を、屋根を外して内部が見える見下ろし2Dフィールド型へ変更。
- TEST環境は本番所持データと分離されるため、★3以下のTEST所持ピックが0件の場合のみ体験用相棒を表示。所持登録は変更しない。
- 既存Simulator / Dungeon / Expedition / Worldのファイルは変更しない。

## Ver0.04 変更点
- 冒険中は町・目標カードを隠し、ダンジョンを主画面化。
- ダンジョン床・壁・採取・階段をタイル風表示へ変更。
- 相棒・敵はMasterDBの画像をフィールド上に表示（画像なし時のみラベル表示）。
- 主人公は絵文字からCSSキャラクター表示へ変更。
- iPhoneでは隣接マスを直接タップして移動可能。
- 町の人物も絵文字依存を減らし、CSSキャラクターへ変更。

## Ver0.04 追加変更点（今回）
- 下部に大きな説明枠を並べる構成を廃止し、拠点・冒険・お店をそれぞれ1画面完結のレイアウトへ再構成。
- 右側コマンド選択方式を導入し、必要な操作をその場で選べるよう変更。
- 拠点・店の人物を、絵文字ではなく見下ろし型のCSS人型キャラクターへ刷新。
- 倉庫・相棒選択・物語・価格設定はオーバーレイウィンドウ方式に変更。
- 店・家・ダンジョンを、同じゲーム画面の延長で見られる方向へUIを調整。
