# Frenda Frontier Ver0.38 / TEST

## Ver0.38 - 最初の実エリア間移動

- 中心開拓地 ↔ 南の街道沿いを、歩行＋境界自動切替で実際に往復できます。
- 南の街道沿いは全体構成確認用の仮実マップです。最終背景・施設座標・NPCルートはまだ固定しません。
- 南の街道が「利用可能」以上のときだけ接続が開通します。TESTの町域指定で確認できます。
- 境界切替時は短いフェード表示を挟み、移動後の位置・現在エリア・訪問済みエリアを保存します。
- 通行判定はエリアごとの nav 定義から生成し、中心マップ専用の当たり判定に依存しません。
- 将来、北・西・東も AREA_DEFS の nav と sceneStatus を追加すれば同じ仕組みで接続できます。

配置先は従来どおり `/test/frontier/`。画像アセットはVer0.33/0.31系を継続利用するため、このZIPには変更ソースのみを収録しています。
